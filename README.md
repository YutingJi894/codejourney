# CodeJourney
Open index.html in a browser. No installation required.

Deploy: create a GitHub repository, upload index.html, then Settings > Pages > Deploy from a branch > main / (root) > Save. Alternatively import the repository into Vercel, choose Other framework, no build command, output directory root (or leave default for static HTML), Deploy.

Data is localStorage, per browser and origin. Export a JSON backup before switching URLs/devices, then import it on the new site. No account or cloud synchronization in this prototype.
